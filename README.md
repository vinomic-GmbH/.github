# .github

Zentrale **org-weite Standarddateien** für `vinomic-GmbH`. Dieses Repo muss dafür public sein
und enthält bewusst nur generische Templates – keine internen Details, keine Secrets.

- `profile/README.md` – Startseite des GitHub-Org-Profils
- `PULL_REQUEST_TEMPLATE.md` – Standard-PR-Vorlage für alle Repos (ein Repo kann sie mit einer eigenen Vorlage überschreiben)
- Weitere Standarddateien (Issue-Templates, CONTRIBUTING, SECURITY) können später ergänzt werden.

Wiederverwendbare Workflows liegen bewusst **nicht** hier, sondern im privaten Repo `actions`.
